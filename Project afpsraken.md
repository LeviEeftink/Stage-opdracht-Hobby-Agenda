# Projectafspraken

- Houd de hobbyagenda eenvoudig: één agendaweergave, zonder opslagkeuze of inlogflow in de app.
- Gebruik PayloadCMS voor activiteiten en localStorage voor een browserkopie.
- Werk op `Feature`, commit en push met korte Nederlandse berichten. Merge afgerond werk naar `Development`.
- Laat het visuele design aan de gebruiker. Gebruik standaard HTML en Tailwind alleen waar dat nodig is voor de structuur.
- Controleer relevante functionaliteit met `npm run check`, `npm test` en `npm run build`.
