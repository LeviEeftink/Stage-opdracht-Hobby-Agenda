# Hobby Agenda

Een eenvoudige lokale hobbyagenda met Next.js, TypeScript en PayloadCMS. Het visuele design volgt later.

## Starten

Gebruik Node.js 22.13+ of 24 LTS.

```bash
npm ci
npm run setup
npm run dev
```

Open http://localhost:3000. Payload gebruikt SQLite (`agenda.db`); ontwikkeling maakt het schema automatisch aan.

Werk op `Feature` en merge afgeronde onderdelen naar `Development`.
